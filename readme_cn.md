## coost 简介

**[coost](https://github.com/idealvin/coost)** 是一个轻量、高性能、易用的 C++ 基础库，支持 Linux、macOS、Windows、FreeBSD 等平台，以及 x86、x64、ARM、ARM64 等 CPU 架构。

**coost** 简称 **co**，包含 go-style 协程、网络、日志、配置解析、单元测试、基准测试、内存分配器等组件，目标是让 C++ 编程变得简单、轻松。
