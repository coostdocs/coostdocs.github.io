    #商业支持

    coost 保持开源。商业支持面向在生产环境使用 coost，或需要跨平台适配、协程 hook、性能优化、团队培训等深度支持的团队，帮助降低风险、节省时间。

    如果你不确定是否需要付费支持，可以先申请一次免费诊断。

    #服务理念

    • coost 本身继续开源，商业支持不影响开源许可证。
    • 付费购买的是时间、确定性和风险控制，而不是代码本身。
    • 先诊断、后报价，尽量让需求和边界清晰。
    • 默认远程支持，现场支持另行协商。
    • 以下价格为参考区间，最终以评估报价为准。

    #服务范围

    • 定制开发：架构适配（RISC-V / MIPS 等）、协程 hook、性能优化、功能定制
    • coost 使用培训、技术咨询与技术培训
    • 年度技术支持与优先响应
    • 复杂技术问题的排查与解决

    编号 套餐 适合场景 建议周期 参考价格

    CS-01 技术咨询 架构、调试、代码评审 按小时 800–1500 元/小时，1 小时起
    CS-02 定制开发 架构适配、协程 Hook、性能优化、功能定制 按项目评估 1–5 万元起，复杂项目按人天 3000–6000 元
    CS-03 团队培训 团队快速上手 coost 1–3 天 0.8–3 万元/天

    CS-05 紧急救援 生产事故、上线卡点 按次 5000 元/次起

    #套餐详情

    #CS-00 免费诊断

    适合谁：已经在用或准备用 coost，但不确定是否需要付费支持的团队。

    交付内容：

    • 30 分钟线上沟通
    • 快速判断问题类型：适配、hook、性能、架构、使用方式
    • 给出初步建议和可选方案
    • 如需要，提供后续套餐报价区间

    客户需提供：

    • 项目背景、目标平台、coost 版本
    • 问题描述、日志、最小复现（如可能）
    • 期望时间点

    不包含：

    • 代码修改
    • 深入排查
    • 书面报告
    • 长期答疑

    #CS-01 技术咨询

    适合谁：

    • 架构选型阶段
    • 遇到具体编译、链接、协程调度、hook 问题
    • 需要代码评审、方案评审
    • 需要有人指导团队自己完成

    交付内容：

    • 线上会议或邮件/Issue 咨询
    • 问题分析、方案建议
    • 关键代码片段或伪代码
    • 会议纪要或结论摘要
    • 可选：PR 评审、设计文档评审

    参考价格：

    • 800–1500 元/小时，1 小时起
    • 单次咨询：1500 元/次（含 1 小时会议 + 30 分钟准备 + 简要纪要）
    • 5 小时包：9 折
    • 10 小时包：8 折
    • 20 小时包：7.5 折

    不包含：

    • 完整功能开发
    • 生产环境部署
    • 7×24 响应
    • 第三方库自身 bug 修复

    #CS-02 定制开发

    适合谁：

    • 需要适配 RISC-V、MIPS 等架构
    • 需要在协程中直接使用第三方网络库，需要协程 hook
    • 需要性能优化：延迟、吞吐、P99 不达标
    • 需要 coost 定制功能、私有协议、调度策略、监控接口、工具链集成

    服务子类与参考价格：

    子类 内容 参考价格 周期
    架构适配 RISC-V / MIPS 等平台编译、运行、基础测试 1–3 万元 1–4 周
    协程 Hook 集成 让指定三方网络库在协程中直接使用 2–5 万元 3–6 周
    性能优化 基线测试、瓶颈分析、调优、复测 1–4 万元 1–4 周
    功能定制 coost 定制功能开发 3000–6000 元/人天，2 万元起 按需求评估

    交付内容：

    • 需求确认、技术设计
    • 代码补丁或模块
    • 测试用例、示例、文档
    • 可选：上游 PR

    验收标准：

    • 按双方确认的需求文档和测试用例验收
    • 架构适配：目标平台编译、运行通过
    • 协程 Hook：指定库在协程中完成连接、请求、响应，超时与取消正常
    • 性能优化：在相同环境下复测，达到约定基线
    • 功能定制：按需求文档验收

    不包含：

    • 第三方库商业授权
    • 硬件、云资源、差旅
    • 客户业务代码大规模重构
    • 长期免费维护
    • 需求蔓延

    #CS-03 团队培训

    适合谁：

    • 新团队引入 coost
    • 从 v3 升级到 v4.0.0
    • 需要内部技术分享
    • 需要协程、网络编程、性能调优培训

    可选形式：

    形式 内容 参考价格
    线上培训 2–4 小时/次 8000–15000 元/天
    线下培训 1–3 天 1.5–3 万元/天
    定制内训 按需求设计课程 面议

    培训主题可选：

    • coost 架构与核心组件
    • 协程原理与调度
    • 网络编程与 hook
    • 跨平台编译与适配
    • 性能分析与优化
    • v3 到 v4.0.0 迁移

    不包含：

    • 差旅、住宿、场地
    • 培训后的长期免费答疑
    • 客户业务代码开发

    #CS-04 年度护航

    适合谁：

    • 已在生产环境使用 coost
    • 需要稳定升级、安全通知、优先响应
    • 不希望每次问题都单独报价

    建议档位：

    档位 包含内容 参考价格
    基础护航 邮件/Issue 优先，工作日 24h 响应，10 小时咨询 3–5 万元/年
    标准护航 工作日 8h 响应，20 小时咨询，季度会议 5–8 万元/年
    高级护航 工作日 4h 响应，50 小时咨询，月度会议，升级支持 8–10 万元/年

    交付内容：

    • 优先 Issue / 邮件支持
    • 版本升级建议
    • 安全漏洞通知
    • 季度/月度技术会议
    • 一定小时数的咨询或小修
    • 紧急问题协调

    不包含：

    • 7×24 全天候支持
    • 新功能定制开发
    • 现场支持
    • 第三方库责任

    #CS-05 紧急救援

    适合谁：

    • 生产环境崩溃、卡死、性能骤降
    • 上线窗口临近
    • 需要快速定位和止损

    交付内容：

    • 远程紧急接入
    • 问题定位
    • 临时修复或规避方案
    • 事后简要报告

    参考价格：

    • 5000 元/次起
    • 超出 2 小时后按 1500–2500 元/小时计费
    • 夜间或节假日加收 50%–100%

    不包含：

    • 现场支持
    • 硬件/网络/云厂商问题
    • 长期根治开发

    #服务流程

    1. 免费诊断
    2. 明确需求与边界
    3. 提供报价与周期
    4. 签订合同或确认邮件
    5. 支付预付款
    6. 执行服务
    7. 验收交付
    8. 尾款与售后

    #付款方式

    • 咨询/培训：预付 100% 或 50%
    • 定制开发：预付 50%，验收后 50%
    • 年度护航：年付，可协商季付
    • 紧急救援：预付或 24 小时内付清
    • 超时按小时计费
    • 差旅实报实销

    #客户需提供

    • 明确需求
    • 可复现环境
    • 日志、代码、权限
    • 指定对接人
    • 及时反馈

    #不包含内容

    • 客户业务逻辑开发
    • 第三方库授权和 bug 修复
    • 硬件、云资源、差旅
    • 7×24 无条件支持
    • 无限次需求变更

    #知识产权与保密

    • coost 本身保持原开源许可证
    • 客户私有代码归客户
    • 定制开发成果按合同约定
    • 可协商将通用改进回馈上游
    • 双方可签 NDA

    #常见问题

    #商业支持会影响 coost 开源吗？

    不会。coost 继续保持开源，商业支持针对的是定制开发、适配、优化、培训等深度服务。

    #可以只买小时咨询吗？

    可以。技术咨询 1 小时起，按小时计费。

    #可以签 NDA 吗？

    可以，具体条款双方协商。

    #支持远程吗？

    默认远程支持。现场支持需另行协商差旅和费用。

    #可以开发票吗？

    可以协商，按实际税点另议。

    #能保证性能提升多少吗？

    可以在服务前约定基线指标，并在相同环境下复测。无法承诺与业务收益直接相关的数字。

    #第三方库的问题负责吗？

    不直接负责第三方库自身问题，但可以协助定位、规避或集成。

    #响应时间多长？

    根据套餐不同，年度护航提供工作日 24h / 8h / 4h 响应。紧急救援按次协商。

    #联系方式

    有需求请通过以下方式联系作者，简单说明项目背景和问题：

    • GitHub Issues: https://github.com/idealvin/coost/issues
    • 邮箱: idealvin@qq.com

    首次沟通可提供一次免费诊断，用于判断问题范围和可行方案。
